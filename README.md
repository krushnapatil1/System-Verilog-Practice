# SystemVerilog Practice Questions

**A collection of SystemVerilog coding exercises, concept-based questions, and interview preparation problems.**

## About This Repository

Welcome to my SystemVerilog Practice Repository!

I created this repository to strengthen my SystemVerilog programming skills through regular coding practice. It contains questions and examples covering fundamental concepts, object-oriented programming, randomization, constraints, and verification-related topics.

My goal is to improve my problem-solving skills and prepare for opportunities as an **RTL Design and Design Verification Engineer**.

## Topics Covered

### 1. SystemVerilog Fundamentals
- Data types and variables
- Operators and expressions
- Procedural blocks
- Tasks and functions
- Static and automatic variables

### 2. Arrays and Data Structures
- Packed and unpacked arrays
- Dynamic arrays
- Associative arrays
- Queues
- Structures and unions

### 3. Object-Oriented Programming (OOP)
- Classes and objects
- Constructors and the `this` keyword
- Inheritance and the `super` keyword
- Shallow copy and deep copy
- Polymorphism and virtual methods
- Virtual classes and pure virtual methods
- Type casting
- Static class properties and methods

### 4. Randomization and Constraints
- `rand` and `randc`
- Constraint blocks
- Inline constraints
- `soft` constraints
- `inside` operator
- `dist` operator
- `rand_mode()` and `constraint_mode()`
- Pre-randomization and post-randomization methods

### 5. Interprocess Communication
- Mailboxes
- Semaphores
- Events
- Process synchronization
- `fork`, `join`, `join_any`, and `join_none`

### 6. Design Verification Concepts
- Testbench development
- Stimulus generation
- Functional checking
- Interfaces and clocking blocks
- Assertions and functional coverage
- Introduction to UVM concepts

## My Practice Approach
